## 🧠 AI 有多"老道"？

AI 不是随机出牌的机器，而是一套完整的**高手行为模型**：

- **记牌推理** —— 统计已出牌与自己的手牌，反推每个点数还剩几张、场上还有几个炸弹
- **手牌估值** —— 计算手数、控制力、炸弹价值，判断自己是强牌抢头游还是弱牌保级
- **灵活配合** —— 队友冲刺时果断放行；队友出小牌被压风险高时主动接权；自己牌力弱时喂牌过渡，把出牌权交给队友
- **审时度势的炸弹观** —— 会组同花顺炸弹、用逢人配升级炸弹，也会果断拆炸单打；对手剩 5 张时积极轰炸，剩 4 张时懂得不浪费炸弹
- **顶格必拦** —— 上家打出大王、级牌这类"该牌型天花板"时，该炸就炸，绝不放任对手白拿一手
- **残局冲刺** —— 手数少时从最大牌型倒序施压，逼对手拆牌或耗炸
- **接风悟性** —— 搭档出完最后一手且无人能压时，第一时间接过领出权

> ⚖️ **但绝不作弊**：AI 的每一步决策只能读取公开信息（已出牌、各家剩牌数、过牌记录）和自己的手牌。它和你在同一条起跑线上。

## 🚀 快速开始

**方式一（推荐）**

1. 下载整个文件夹（含 `掼蛋.html` 与 `掼蛋语音包/`）

## 📖 玩法速览（掼蛋规则）

**掼蛋**是流行于江淮地区的四人两队扑克游戏，对家为队友，目标是尽快出完手牌并升级。

- **牌张**：两副牌 108 张，每人 27 张
- **级牌**：从 2 打起，级牌大于 A、小于王
- **逢人配**：红桃级牌是百搭牌，可代替除大小王外任意牌 —— 组炸弹、凑顺子全凭想象
- **牌型**：单张 · 对子 · 三张 · 三带二 · 顺子 · 三连对 · 钢板 · 炸弹 · 同花顺 · 天王炸
- **进贡还贡**：上局的末游要把最大的牌进贡给头游，头游回礼一张小牌
- **升级**：头游方升级，双下升两级；打过 A 者赢得整场

## 🛠 技术特点

- **单文件全内联** —— HTML + CSS + JavaScript 一体，零 CDN、零外链
- **离线可玩** —— 不使用任何网络请求，断网、无网环境照常运行
- **纯 DOM + CSS 动画** —— 出牌飞行、炸弹特效、进贡动画全部基于 `transform/opacity`，稳定 60fps
- **音频队列机制** —— `onended` + `onerror` + 超时三重兜底，杜绝语音卡死
- **AI 决策缓存** —— 牌型识别与手数计算带缓存，复杂牌局决策亦在毫秒级完成
- **自检机制** —— 打开控制台可见内置规则自检（17/17 项通过）
